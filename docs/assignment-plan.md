# План работы по заданию

Основа: существующая постановка задачи — успех Kickstarter до запуска, исходный CSV и прежний блокнот. Пользователь поручил выполнение с выбором деталей по прошлым работам.

1. Создать `01_Kickstarter_Analysis.ipynb`: аудит исходных данных, детерминированная очистка с журналом, случайные 25% для анализа, средние/медианы, графики, три гипотезы и проверка на остальных 75%, поправка Холма, выводы.
2. Создать `02_Kickstarter_Preprocessing.ipynb`: та же очистка, стратифицированное разбиение 80/20; сравнение StandardScaler, MinMaxScaler, RobustScaler, log1p + StandardScaler по train; графики до/после; обоснование обработки каждого столбца; обучаемый только на train ColumnTransformer.
3. Выполнить оба блокнота целиком. Проверить отсутствие ошибок, пересечений выборок, NaN/inf и утечек итоговых показателей в признаки. Сохранить выводы и графики.
4. Обновить README и зависимости. Сохранить прежний изменённый пользователем блокнот. Зафиксировать только новые материалы и обновлённый README, отправить в существующий GitHub при доступной авторизации.

Очистка до разделения использует только заранее заданные правила, без оценки медиан, квантилей и частот для заполнения. Все обучаемые преобразования — после train/test. Названия кампаний не являются ключом дедупликации; экстремальные положительные цели не считаются автоматически ошибкой.
