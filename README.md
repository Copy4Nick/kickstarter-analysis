# Kickstarter — индивидуальный цифровой проект

Задача из предыдущего этапа: прогнозировать успех кампании Kickstarter по характеристикам, известным до запуска. Источник — [Kickstarter Projects, kemical / Kaggle](https://www.kaggle.com/datasets/kemical/kickstarter-projects), файл `ks-projects-201801.csv` (378 661 строка, 15 столбцов).

## Два блокнота для сдачи

1. [01_Kickstarter_Analysis.ipynb](01_Kickstarter_Analysis.ipynb) — аудит и очистка с объяснением правил и журналом изменений; случайные 25% для анализа; распределения цели и длительности, средние и медианы; три гипотезы с описанием рассуждений; проверка на оставшихся 75% с поправкой Холма; выводы.
2. [02_Kickstarter_Preprocessing.ipynb](02_Kickstarter_Preprocessing.ipynb) — та же очистка; train/test 80/20; StandardScaler, MinMaxScaler, RobustScaler и log1p + StandardScaler для цели в USD; графики до и после; сравнение и выбор метода; обработка всех остальных полей с обоснованием. Обучаемые преобразования оцениваются только на train.

Оба блокнота независимы друг от друга, содержат выполненные ячейки, таблицы и встроенные графики. Исходный CSV не изменяется. `Kickstarter_Dataset_Overview.ipynb` — сохранённая предыдущая работа, к новым двум блокнотам не относится.

## Запуск

Python 3.11 или новее. Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Открыть нужный блокнот и выполнить **Restart Kernel and Run All Cells**. Рабочая папка — корень репозитория, CSV уже находится в нём. Случайные разбиения воспроизводимы (`random_state=42`). Обучение модели не входит в эту работу.

## Основные результаты выполнения

- Полных дубликатов и повторов ID нет; совпадающие названия разных кампаний сохранены.
- Исключены 7 ошибочных дат, 46 979 остальных строк вне бинарной задачи и 11 противоречий статуса и суммы. После очистки — 331 664 проекта, без пропусков в сохранённых столбцах. Неверная страна заменена на `Unknown`, отсутствующее название — пустой строкой; дублирующий итоговый столбец `usd pledged` удалён с объяснением.
- Анализ: 82 916 строк; независимая проверка гипотез: 248 748 строк. На проверочной части цель до 5000 USD связана с большей долей успеха на 17,36 п.п., срок до 30 дней — на 1,37 п.п., Dance против Technology — на 41,36 п.п. Все три направленные гипотезы поддержаны после поправки Холма; это связи, а не доказательство причинности.
- Предобработка: train — 265 331, test — 66 333 строки; по 221 выходному признаку. Для цели выбран log1p + StandardScaler: асимметрия train уменьшилась с 82,76 до −0,14. Итоговые разреженные матрицы не содержат NaN/inf.

Разбиение 25/75 для гипотез и разбиение 80/20 для предобработки имеют разное назначение. Во второй части модель не оценивается. Данные исторические (2009–2018), перенос выводов на современные кампании требует новой проверки.
